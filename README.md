MSCIT Institute 🎓
Institute Management Website
A complete website built for a real MSCIT (MS-CIT) computer training institute — managing student details, courses, fees, and institute information, all through a clean admin-controlled system.

💡 The Purpose
Built for a real institute to replace manual record-keeping with a digital system. Staff can manage student enrollments, course details, and fee records through a simple web interface.

✨ Features

Institute homepage with course listings
Student details management
Course and fees information
Admin panel for data management
Clean professional UI for institute branding

🗄️ Database
vinesh.sql contains the complete schema:

Students table — name, enrollment, fees status
Courses table — course name, duration, fees
Admin table — login credentials
